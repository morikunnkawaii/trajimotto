# トラジモット
## サイト概要
### サイトテーマ
だれでも自由に自分が知っている地元の穴場スポットを投稿したり閲覧出来るSNSサイト
​
### テーマを選んだ理由
元々地元と自然が好きで地元を散策していたのですが、検索しても出てこないような所でとてもいい場所を知っています。
なので他県の観光スポットでもそういう人が知らない穴場スポットに行きたくて検索をかけるのですが、どうしても有名な観光地が検索上位に引っ掛かり自分が行きたいような場所を探し出せません。
なのでそれ専用のサイトを立ち上げたいと思いこのテーマにしました。

### ターゲットユーザ
・旅行好きな人で普段行く場所に飽きてしまった人
・知る人ぞ知る観光穴場スポットに行ってみたい人
​
### 主な利用シーン
旅行で観光穴場スポットを検索する
自分が知っている観光穴場スポットを投稿する
投稿された観光穴場スポットのレビューを投稿閲覧する
